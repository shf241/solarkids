## 三、公共动画接口骨架

### 1. 开发目标

- 项目内只保留一个长期运行的 `requestAnimationFrame` 主循环。
- 日月食、磁场、太阳风和彗星共享统一时间倍率。
- 主场景与叠加专题图层职责分离。
- 模块间通过公开天体状态协作，避免直接修改彼此内部数据。
- 场景和图层退出时有统一资源清理入口。
- 公共接口先实现最小可用版本，再通过模块1和模块6逐步稳定。

### 2. AI 辅助生成内容

AI 辅助生成了以下初始实现：

- `AnimationClock`：真实时间、模拟时间、时间倍率和最大帧间隔。
- `AnimationController`：播放、暂停、继续、停止、重置和统一帧调度。
- `SceneManager`：主场景注册、切换、更新、渲染、退出和销毁。
- `LayerManager`：专题图层挂载、排序、启用、禁用和卸载。
- `Camera2D`：相机状态、缩放、平移、旋转和坐标转换。
- `WorldStateStore`：天体状态写入、查询和事件通知。
- `EventBus`：公共运行时事件通信。
- `CanvasRuntime`：组合以上模块并统一处理 Canvas 尺寸和 DPR。
- `controlBridge`：兼容当前 UI 自定义事件。

### 3. 学生审阅与设计修改

结合现有项目，学生确认并保留了以下设计：

1. 暂时保留静态太阳系预览，公共运行时在没有激活场景时不覆盖画面。
2. 主场景用于互斥模式，图层用于太阳风、磁场线和教学标注等叠加效果。
3. 模块1负责写入天体状态，成员1和成员4只读取公开状态。
4. 动画帧调度支持依赖注入，便于使用模拟帧做单元检查。
5. 浏览器切换后台时限制最大帧间隔，避免恢复后天体突然跳跃。
6. 相机状态和天体状态对外返回副本，减少跨模块意外修改。
7. UI 事件通过兼容桥接入，避免公共骨架一次性重写现有界面。

### 5. 验证结果

- TypeScript 5.9.3 严格模式编译通过。
- 动画时钟、动画状态、相机、坐标转换和状态副本隔离检查通过。
- 场景和图层生命周期检查通过。
- 无界面核心检查共通过 33 项断言。
- 浏览器中成功获取唯一 `CanvasRuntime`。
- `idle → running → paused → running → stopped` 状态转换正常。
- 时间倍率设置正常。
- 世界坐标和屏幕坐标往返转换正常，仅存在浮点精度范围内误差。
- 临时动画场景可以持续运动，时间倍率可以改变运动速度。
- 天体状态可以正常写入和读取。
- 未激活正式场景时，现有静态预览保持正常。

### 6. 独立判断

公共动画接口没有直接实现所有专题业务，而是先解决团队协作中的共享问题。这样可以避免每个专题各自创建动画循环、相机和坐标系，也减少多人同时修改 `src/main.ts` 和 Canvas 核心文件的冲突。
