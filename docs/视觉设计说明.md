### 行星专属色

| 天体 | 色值 | 设计依据 |

| 水星 | `#b0b0b0` | 灰色，水星表面岩石色 |
| 金星 | `#e8cda0` | 浅棕黄，金星大气色 |
| 地球 | `#4da6e8` | 蓝色，海洋覆盖的蓝色星球 |
| 月球 | `#cccccc` | 浅灰，月表色 |
| 火星 | `#d45a3a` | 红棕色，火星标志性红色 |
| 木星 | `#d4b896` | 浅棕条纹，木星大气纹理色 |
| 土星 | `#e8d5a3` | 暖米色，土星大气 + 光环 |

| 海王星 | `#4b7ef7` | 深蓝，海王星深海蓝 |

### 儿童视觉考虑

- **无荧光色**：不使用 `#ff0000`、`#00ff00` 等纯色，避免视觉刺激
- **无强对比**：星空背景深蓝与暖金色文字形成柔和对比，而非黑白对比
- **饱和度适中**：行星颜色都在 60%-80% 饱和度区间，鲜艳但不刺眼
- **颜色区分明确**：八大行星各有独立颜色，方便儿童一眼识别

## 四、设计风格

### 整体定位

**"深空科技感 + 卡通童趣"** 混合风格：

- **深色太空背景**：模拟宇宙视角，降低屏幕亮度减少视觉疲劳
- **圆角友好元素**：所有卡片、按钮使用 12px-16px 圆角，消除尖锐感
- **大按钮 + 大图标**：最小触摸目标 44×44px，符合移动端可访问性标准
- **柔和阴影与光晕**：用 `box-shadow` 模拟星球光晕，营造空间感

### 动画原则

- **平滑过渡**：使用 `ease` 缓动，不突兀
- **适度反馈**：按钮点击有缩放效果（`scale(0.96)`），给予即时操作确认
- **避免闪烁**：不使用 `animation` 无限闪烁效果
- **颜色过渡**：悬停时颜色渐变而非跳变（`transition: 0.15s ease`）

## 五、换肤系统

### 卡通模式（缺省）

- 使用 **SVG 内嵌渐变** 绘制行星
- 色彩更鲜艳、造型简洁
- 代码自动生成，无需外部素材
- 适合低龄儿童（5-8岁）

### 写实模式

- 使用 **PNG 纹理贴图** 展示真实行星表面
- 纹理素材放在 `assets/images/`
- 更接近 NASA 真实照片风格
- 适合年龄稍大的儿童（9-12岁）

### 切换方式

- 点击底部控制栏 `🎨` 按钮
- 弹出皮肤选择面板
- 选择后立即生效，Canvas 自动重绘

## 六、响应式策略

| 断点 | 布局变化 | 组件行为 |
|------|----------|----------|
| ≥1024px | Grid: 1fr / 320px | 侧面板固定，控制栏一行 |
| 768-1023px | Grid: 单列 | 侧面板移至底部，控制栏折行 |
| <768px | Grid: 单列 | 侧面板浮层弹出，按钮缩小，标签隐藏 |

### 关键指标

- 手机端按钮最小 `40×40px`
- 弹窗最大宽度 `95vw`
- 面板最大高度 `30vh`（手机端）
- 使用 `100dvh` 动态视口高度，解决移动端地址栏遮挡

## 十、静态太阳系原型

为了让成员2的 UI 成果在成员3动画完成前也能直观看到，新增了 Canvas 静态太阳系原型。

完成内容：

- 静态星空背景，使用渐变和点状星星营造深空氛围。
- 太阳使用渐变和光晕绘制，突出画面中心。
- 八大行星使用卡通特征绘制，不只是纯色圆点：
  - 水星：灰色岩石和陨石坑。
  - 金星：米黄色云层弧线。
  - 地球：蓝色海洋、绿色陆地和白色云带。
  - 火星：红色表面和深色地貌。
  - 木星：横向条纹和大红斑。
  - 土星：倾斜光环。
  - 天王星：冰蓝色和柔和云带。
  - 海王星：深蓝色和风暴纹理。
- 额外加入冥王星作为矮行星彩蛋，使用小尺寸、远距离轨道和浅色心形区域帮助儿童记忆。
- 额外加入彗星和斜向彗星轨道，彗尾使用渐变绘制，增强画面趣味性。
- 轨道间距采用“真实日距的平方根压缩”方式：保留内外行星距离逐渐拉开的感觉，但避免真实比例过大导致画面放不下。
- 轨道默认留出更大间距，方便成员3后续加入公转动画、自转动画、彗星动态尾巴和视角切换。
- 鼠标悬停行星时出现蓝色高亮圈。
- 点击行星后出现黄色选中圈，并更新右侧行星知识卡片。
- 放大、缩小、重置视角按钮可以影响静态太阳系预览。

设计边界：

- 当前版本属于成员2的“静态视觉原型”，用于确定儿童化界面效果和交互状态。
- 后续成员3可以在 `src/canvas/` 中实现真实公转、自转、彗星轨道和动态彗尾，再替换或接管该预览逻辑。
