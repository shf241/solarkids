| `#c4d0e8` | 次要文字（描述、标签） |

### 行星专属色

| 天体 | 色值 | 设计依据 |

| 水星 | `#b0b0b0` | 灰色，水星表面岩石色 |
| 金星 | `#e8cda0` | 浅棕黄，金星大气色 |
| 地球 | `#4da6e8` | 蓝色，海洋覆盖的蓝色星球 |
| 月球 | `#cccccc` | 浅灰，月表色 |
| 火星 | `#d45a3a` | 红棕色，火星标志性红色 |
| 木星 | `#d4b896` | 浅棕条纹，木星大气纹理色 |

### 儿童视觉考虑

- **无荧光色**：不使用 `#ff0000`、`#00ff00` 等纯色，避免视觉刺激
- **无强对比**：星空背景深蓝与暖金色文字形成柔和对比，而非黑白对比
- **饱和度适中**：行星颜色都在 60%-80% 饱和度区间，鲜艳但不刺眼
- **颜色区分明确**：八大行星各有独立颜色，方便儿童一眼识别

## 四、设计风格

### 整体定位

**"深空科技感 + 卡通童趣"** 混合风格：

- **深色太空背景**：模拟宇宙视角，降低屏幕亮度减少视觉疲劳
- **圆角友好元素**：所有卡片、按钮使用 12px-16px 圆角，消除尖锐感
- **大按钮 + 大图标**：最小触摸目标 44×44px，符合移动端可访问性标准
- **柔和阴影与光晕**：用 `box-shadow` 模拟星球光晕，营造空间感

### 动画原则

- **平滑过渡**：使用 `ease` 缓动，不突兀
- **适度反馈**：按钮点击有缩放效果（`scale(0.96)`），给予即时操作确认
- **避免闪烁**：不使用 `animation` 无限闪烁效果
- **颜色过渡**：悬停时颜色渐变而非跳变（`transition: 0.15s ease`）

## 五、换肤系统

### 卡通模式（缺省）

- 使用 `assets/cartoon_skin/` 下的 **2:1 PNG 经纬纹理**
- 色彩更鲜艳、造型简洁
- 与写实模式共享球面投影、光照、自转和全方位探访逻辑
- 适合低龄儿童（5-8岁）

### 写实模式

- 使用 **2K 经纬纹理贴图** 展示真实行星表面
- 纹理素材放在 `assets/skins/`
- 更接近 NASA 真实照片风格
- 适合年龄稍大的儿童（9-12岁）

### 切换方式

- 点击底部控制栏 `🎨` 按钮
- 弹出皮肤选择面板
- 选择后立即生效，Canvas 自动重绘

### 侧栏天体标题

- 信息面板第一行采用“天体图标 + 中文名称”的横向结构，例如地球图标后显示“地球”。
- 卡通模式读取 `assets/svg/{bodyId}.svg`，写实模式读取 `assets/images/{bodyId}.png`。
- 标题图标使用 `1em × 1em`，与后方文字等大并保持在同一行；统一使用 `object-fit: contain` 防止土星等宽图标变形。
- 普通状态显示“图标 + 地球”，探访状态显示“图标 + 正在探访地球”。
- 标题图标属于辅助识别信息，使用空 `alt`，避免读屏重复播报后面的中文名称。

## 六、响应式策略

| 断点 | 布局变化 | 组件行为 |
|------|----------|----------|
| ≥1024px | Grid: 1fr / 320px | 侧面板固定，控制栏一行 |
| 768-1023px | Grid: 单列 | 侧面板移至底部，控制栏折行 |
| <768px | Grid: 单列 | 侧面板浮层弹出，按钮缩小，标签隐藏 |

### 关键指标

- 手机端按钮最小 `40×40px`
- 弹窗最大宽度 `95vw`
- 面板最大高度 `30vh`（手机端）
- 使用 `100dvh` 动态视口高度，解决移动端地址栏遮挡

## 十、静态太阳系原型

为了让成员2的 UI 成果在成员3动画完成前也能直观看到，新增了 Canvas 静态太阳系原型。

完成内容：

- 星空背景按皮肤读取对应纹理，并与相机缩放和平移同步。
- 卡通模式使用小星点版本背景，避免装饰星尺寸超过水星、火星等小型行星。
- 太阳在两种皮肤下都使用球面纹理和自发光光晕。
- 八大行星的卡通经纬纹理保留各自识别特征：
  - 水星：灰色岩石和陨石坑。
  - 金星：米黄色云层弧线。
  - 地球：蓝色海洋、绿色陆地和白色云带。
  - 火星：红色表面和深色地貌。
  - 木星：横向条纹和大红斑。
  - 土星：倾斜光环。
  - 天王星：冰蓝色和柔和云带。
  - 海王星：深蓝色和风暴纹理。
- 冥王星矮行星彩蛋已暂时从当前太阳系总览移除，页面集中展示八大行星。
- 彗星已迁移到独立专题场景，不在太阳系总览中混合显示。
- 八大行星使用真实平均半径的地球半径比作为数据源，并通过统一的 `6 × 半径比^0.6` 映射为显示半径；最小半径为 `3.5`，避免类地行星在触屏上完全不可见。
- 轨道使用真实半长轴 AU 作为数据源，通过 `42 + 40.3 × AU^0.68` 统一压缩。相较旧的平方根映射，内行星更靠近太阳，木星之后的轨道间距更明显地拉开。
- 总览轨道统一使用细虚线：普通行星轨道约 `0.65px`，地球和月球强调轨道约 `1.1px`，hover 时约 `1.8px`。
- 太阳显示半径限制为 `42`，月球限制为 `3.5`。这是为了画布可读性保留的视觉上下限，不代表天体与轨道采用同一绝对比例尺。
- 鼠标悬停行星时出现蓝色高亮圈。
- 点击行星后出现黄色选中圈，并更新右侧行星知识卡片。
- 放大、缩小、重置视角按钮可以影响静态太阳系预览。

设计边界：

- 本节记录成员2早期“静态视觉原型”的设计来源；当前页面已经由成员3的 `solar-system` 正式场景接管。
- 旧预览绘制函数只作为少量降级视觉工具保留，不再启动独立动画或事件监听。
