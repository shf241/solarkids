## Canvas 公共动画骨架

### 当前静态检查

- [x] 公共运行时不激活场景时，不主动清空现有静态预览。
- [x] 动画控制器只维护一个待执行的 `requestAnimationFrame`。
- [x] 暂停和恢复会丢弃旧时间戳，避免首帧时间跳跃。
- [x] 帧间隔设置上限，避免浏览器后台恢复后出现大步长。
- [x] 主场景和专题图层都有退出、卸载与清理入口。
- [x] 相机状态和天体状态对外返回副本，避免跨模块直接篡改。
- [x] 现有播放、速度、缩放、重置和专题按钮事件已接入兼容桥。

### 浏览器手动验证

测试日期：2026-07-25

测试方式：在本地开发页面打开浏览器 DevTools，通过公共运行时 API 和临时测试场景进行验证。

- [x] `zoomBy()`、`panByScreen()`、`rotateBy()` 和 `reset()` 调用正常。
- [x] 临时动画场景可以注册、切换并持续绘制运动物体。
