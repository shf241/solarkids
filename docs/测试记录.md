```text

/dist/i18n/i18n
/dist/storage/defaults
/dist/storage/storage
```

补齐 `.js` 后，上述请求均返回成功，应用初始化和按钮事件恢复。该问题不会被
TypeScript 类型检查或 Node 单元测试发现，因此保留浏览器原生 ESM 验收为发布前必测项。
