# SolarKids 成员4模块对接说明

## 一、模块状态

成员4纯逻辑模块与产品接入层已经完成。纯逻辑仍不依赖 DOM，
Canvas 场景通过成员3的公共运行时接入：

| 模块 | 入口 | 用途 |
| --- | --- | --- |
| 数据存储 | `src/storage/index.ts` | 保存语言、皮肤、学习进度和游戏记录 |
| 多语言 | `src/i18n/index.ts` | 读取中英文文案和切换语言 |
| 小游戏 | `src/game/index.ts` | 计算拖动偏移、变化等级、分数和结果 |
| 双语数据 | `src/data/language.json` | 界面、提示和八大行星知识文案 |
| 产品接入 | `src/integration/index.ts` | 统一语言、皮肤、学习进度与 DOM 翻译 |
| 太阳风场景 | `src/canvas/scenes/solarWindScene.ts` | 模块4三种观察模式 |
| 小游戏场景 | `src/canvas/scenes/orbitGameScene.ts` | 指针拖动、轨道反馈、结算与重置 |

验证命令：

```bash
npm install
npm run typecheck
npm test
npm run build
```

## 二、稳定标识约定

### 2.1 行星 ID

Canvas、学习进度和小游戏统一使用：

```text
mercury
venus
earth
mars
jupiter
saturn
uranus
neptune
```

不得使用中文名称作为数据 ID。中文和英文名称通过 `translate("planet.earth.name")` 等文案键取得。

### 2.2 皮肤 ID

当前稳定皮肤 ID 为：

```text
cartoon
realistic
```

默认值是 `cartoon`。Storage 只保存 ID，不绑定 CSS 类名、图片路径或 SVG 文件名。

### 2.3 存储键

所有用户数据统一保存在：

```text
solarkids.user-state.v1
```

其他模块不要直接写入该键，应通过 Storage 公开接口更新。

## 三、成员2的 UI 接入

### 3.1 语言切换

```ts
import { getLanguage, setLanguage, translate } from "./i18n/index.js";

setLanguage("en");

const currentLanguage = getLanguage();
const startText = translate("action.start");
const earthName = translate("planet.earth.name");
```

UI 职责：

1. 用户点击语言按钮时调用 `setLanguage("zh-CN")` 或 `setLanguage("en")`。
2. 切换后重新渲染带文案键的可见文字。
3. 不在 UI 内维护第二份语言状态。
4. 不直接读取或写入 LocalStorage。

### 3.2 皮肤保存

```ts
import { loadUserState, setSkin } from "./storage/index.js";

setSkin("realistic");
const savedSkinId = loadUserState().skinId;
```

UI 职责：

1. 将皮肤选项映射为稳定 `skinId`。
2. 调用 `setSkin` 后立即更新外观。
3. 页面启动时读取 `loadUserState().skinId` 并应用皮肤。
4. 未识别 ID 时显示 `cartoon`，不要让页面启动失败。

### 3.3 学习进度

```ts
import {
  markPlanetVisited,
  markTaskCompleted,
} from "./storage/index.js";

markPlanetVisited("earth");
markTaskCompleted("learn-earth");
```

点击行星并成功显示知识卡片后记录访问；完成明确学习任务后记录任务 ID。

## 四、成员3的 Canvas 接入

### 4.1 创建与拖动

```ts
import {
  createGameState,
  movePlanet,
  type OrbitGameState,
} from "./game/index.js";

let gameState: OrbitGameState = createGameState(
  "earth",
  { x: earth.x, y: earth.y },
);

gameState = movePlanet(gameState, {
  x: pointerCanvasX,
  y: pointerCanvasY,
});
```

Canvas 职责：

1. 完成指针事件和行星命中检测。
2. 将页面坐标转换为 Canvas 内部坐标。
3. 只传入有限数值。
4. 根据 `currentPosition` 绘制行星。
5. 根据 `changeLevel` 显示轨道变化反馈。

变化规则：

| 偏移量 | `changeLevel` | 分数 | 完成 |
| --- | --- | --- | --- |
| 0至5 | `stable` | 0 | 否 |
| 大于5且小于60 | `small` | 50 | 否 |
| 大于等于60 | `large` | 100 | 是 |

偏移量是当前位置相对游戏初始位置的直线距离。此规则是儿童教学近似，不是精确引力或轨道物理仿真。

### 4.2 重置

```ts
import { resetGame } from "./game/index.js";

gameState = resetGame(gameState);
```

调用后 Canvas 应使用返回状态的 `currentPosition` 恢复行星位置，并恢复默认轨道视觉。

### 4.3 完成与保存

```ts
import { saveOrbitGameResult } from "./game/index.js";

const { result, userState } = saveOrbitGameResult(gameState);
```

只在一次游戏正式结束时调用一次。拖动过程中不要重复保存，否则会重复增加 `playCount`。

## 五、异常和回退行为

| 场景 | 模块行为 | 接入层行为 |
| --- | --- | --- |
| 首次访问 | 返回完整默认状态 | 直接使用 |
| LocalStorage 被禁用或已满 | 捕获异常，应用继续运行 | 可显示非阻断提示 |
| 存储 JSON 损坏 | 返回默认状态 | 不需要自行解析 |
| 非法语言 | 回退 `zh-CN` | 重新渲染中文 |
| 文案键缺失 | 先回退中文，再显示键名 | 检查并补充词典 |
| 拖动坐标非有限数值 | 抛出 `TypeError` | 坐标转换后先校验 |
| 未识别皮肤 ID | Storage 仍保存字符串 | UI 回退 `cartoon` |

## 七、公共场景接口

成员4场景统一由 `registerMember4Scenes()` 注册：

| 场景 | 场景 ID | DOM 事件 |
| --- | --- | --- |
| 太阳雨入口下的太阳风教学动画 | `solar-rain` | `solarkids:showSolarRain` |
| 轨道小游戏 | `orbit-game` | `solarkids:showOrbitGame` |

两个场景都遵守 `CanvasScene` 生命周期，不创建独立
`requestAnimationFrame`。退出场景时会移除自身指针和键盘监听器。

`solar-rain` 是成员3在最新 `dev` 中确定的公共入口协议。成员4只把已有
太阳风动画接入该协议，不再注册 `solar-wind` 场景，也不增加第二个太阳风按钮。

太阳风采用三种教学观察模式：

- `radial`：太阳风从太阳向外辐射。
- `shield`：粒子在地球磁层前方发生偏转。
- `aurora`：少量粒子沿磁力线进入极区。

这三种模式是概念可视化，不输出真实空间天气数值。
