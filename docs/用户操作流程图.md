# SolarKids 用户操作流程图

## 一、设计目标

本流程图面向 7-12 岁儿童用户，目标是让孩子可以在 3 步左右完成一次核心学习任务。流程遵循“先看见、再点击、再探索、再反馈”的认知顺序，减少复杂菜单和文字说明，让主要操作都能通过明显按钮、图标和动画反馈完成。首次打开先经过欢迎页，点击“开始探索”后才进入太阳系主界面。

## 二、核心用户路径

### 路径1：观察太阳系运行

```mermaid
flowchart TD
    A["打开 SolarKids"] --> B["欢迎页加载完成"]
    B --> C["点击开始探索"]
    C --> D["观察太阳、行星、月球和轨道动画"]
    D --> E["点击播放或暂停控制动画"]
```

操作步数：3 步（进入、观察、控制）。

儿童理解逻辑：

- 打开页面先看到带有星空、太阳和功能标签的欢迎页，素材准备完成后“开始探索”按钮才可用。
- 点击“开始探索”后欢迎层淡出，主界面动画启动，避免初始化未完成时误操作。
- 通过动画理解行星围绕太阳运行。
- 可随时暂停，避免信息过快。
- 首次进入时使用简短欢迎提示，引导儿童点击天体开始探索。

### 路径2：查看某个行星知识

```mermaid
flowchart TD
    A["进入太阳系运行界面"] --> B["点击一个行星"]
    B --> C["右侧或下方信息面板更新"]
    C --> D["查看图标、特点、数据和科普短句"]
    D --> E["点击探访按钮或继续选择其他天体"]
```

操作步数：4 步。

儿童理解逻辑：

- 直接点击感兴趣的行星。
- 不要求先理解复杂菜单。
- 信息面板使用短句、关键词、图形和简短数据。
- 电脑端显示在右侧，手机端显示在 Canvas 下方。

### 路径3：缩放和切换视角

```mermaid
flowchart TD
    A["进入太阳系运行界面"] --> B["点击放大/缩小或使用滚轮、双指手势"]
    B --> C["画面平滑缩放"]
    C --> D["点击太阳系总览或地表视角"]
    D --> E["观察整体运行或地表天空"]
```

操作步数：4 步。

儿童理解逻辑：

- 放大、缩小使用常见图标。
- 支持按钮、鼠标和触摸手势，不要求设置复杂参数。
- 缩放过程使用平滑动画，减少眩晕。

### 路径4：更换天体皮肤

```mermaid
flowchart TD
    A["点击皮肤按钮"] --> B["打开皮肤面板"]
    B --> C["选择卡通模式或写实模式"]
    C --> D["画面立即更新并保存选择"]
```

操作步数：3 步。

儿童理解逻辑：

- 使用颜色和缩略图帮助选择。
- 皮肤变化立即反馈。
- 选择结果保存到 LocalStorage，下次打开仍然生效。

### 路径5：切换中英文科普

```mermaid
flowchart TD
    A["点击语言按钮"] --> B["中文与 English 立即切换"]
    B --> C["点击天体查看对应语言知识"]
```

操作步数：2 步。

儿童理解逻辑：

- 语言入口放在固定位置。
- 切换后立刻看到变化。
- 英文使用儿童科普短句，避免长段落。

### 路径6：拖动行星小游戏

```mermaid
flowchart TD
    A["点击轨道小游戏"] --> B["进入轨道探索模式"]
    B --> C["向内或向外拖动地球"]
    C --> D["观察轨道半径与提示变化"]
    D --> E["松开地球查看结果反馈"]
    E --> F["点击重置再次尝试"]
```

操作步数：5 步。

儿童理解逻辑：

- 用“拖一拖、看变化”的方式理解轨道半径。
- 不要求输入数值或公式。
- 完成有效拖动后再显示结果，避免轻触产生错误记录。
- 重置按钮保证孩子可以反复尝试。

### 路径7：探索天文专题

```mermaid
flowchart TD
    A["进入太阳系运行主界面"] --> B["选择专题入口"]
    B --> C["日食/月食"]
    B --> D["哈雷彗星"]
    B --> E["太阳与地球磁场"]
    B --> F["太阳风实验室"]
    C --> G["切换模式、视角并观察动画"]
    D --> G
    E --> G
    F --> G
    G --> H["点击太阳系总览返回主界面"]
```

操作步数：4 步以内。

儿童理解逻辑：

- 专题入口与太阳系总览并列显示，避免进入多层菜单。
- 不同专题共用播放、暂停和速度控制。
- 日食/月食、磁场和太阳风提供分模式观察。
- 点击“太阳系总览”可随时返回主界面。

### 路径8：AI 天文问答顾问

```mermaid
flowchart TD
    A["点击 AI 天文小顾问"] --> B["输入一个宇宙问题"]
    B --> C["点击提问"]
    C --> D["查看儿童友好回答和继续探索提示"]
```

操作步数：3 步。

儿童理解逻辑：

- 顾问入口使用机器人图标，和学习场景入口放在同一控制栏。
- 提供“日食、磁场、彗星”等示例问题，减少不知道怎么问的问题。
- 回答采用离线知识卡片匹配，不需要输入账号或 API Key；未知问题会给出鼓励性引导。

### 路径9：WebSocket 多人学习房

```mermaid
flowchart TD
    A["点击多人学习房"] --> B["输入名字和房间号并加入"]
    B --> C["查看同房间同学的学习动作"]
```

操作步数：2 步。

儿童理解逻辑：

- 两个浏览器标签输入同一个房间号即可进入同一学习空间。
- WebSocket 连接成功时显示在线人数，场景切换和探访天体会出现在活动列表。
- 未启动协作服务时仍可使用同浏览器演示同步，并在弹窗中提示启动 `npm run collab`。

## 四、关键交互原则

1. 核心功能入口始终可见，避免儿童在多层菜单中迷路。
2. 所有主要功能控制在 5 步以内完成。
3. 按钮使用图标加简短文字，例如“播放”“暂停”“放大”“太阳系总览”。
4. 重要反馈使用动画、颜色变化和提示语共同表达。
5. 出错或无效操作时不使用严厉提示，改用鼓励性语言，例如“再试一次看看轨道怎么变”。
6. 保留“太阳系总览”和“重置”入口，让儿童可以放心探索。
