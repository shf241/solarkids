# SolarKids 成员1日月食与磁场模块说明

## 一、负责范围

- 模块2：日食与月食模拟。
- 模块3：太阳磁场与地球磁场演示。

两个模块均使用成员3提供的公共 `CanvasRuntime`，不创建额外的
`requestAnimationFrame` 循环。

## 二、文件结构

```text
src/canvas/scenes/
├── eclipseScene.ts
├── magneticScene.ts
├── registerMember1Scenes.ts
└── sceneVisuals.ts
```

- `eclipseScene.ts`：日食、月食、全景和地球视角。
- `magneticScene.ts`：太阳磁场、地球磁场和磁场对比模式。
- `registerMember1Scenes.ts`：统一注册两个专题场景。
- `sceneVisuals.ts`：专题场景共用的背景、按钮、时间轴和标签绘制工具。

## 三、日食与月食模块

场景 ID 为 `eclipse`，现有“日食/月食”按钮会自动切换到该场景。

功能包括：

- 日食和月食模式切换。
- 全景视角和地球视角切换。
- 根据当前换肤模式使用卡通 SVG 或写实 PNG 的太阳、地球和月球素材。
- 太阳、地球、月球关键位置标注。
- 本影方向和遮挡关系演示。
- 时间轴和事件过程提示。
- 播放、暂停和统一时间倍率控制。
- 键盘数字 `1`、`2` 切换日食和月食。
- 键盘 `V` 切换观察视角。

## 四、磁场模块

场景 ID 为 `magnetic`，现有“磁场”按钮会自动切换到该场景。

功能包括：

- 太阳磁场和地球磁场对比。
- 太阳磁场单独观察。
- 地球磁场单独观察。
- 太阳和地球跟随当前卡通/写实换肤素材。
- 对比模式下，地球沿椭圆轨道绕太阳公转。
- 磁极、磁轴和磁力线随天体运动动态变化。
- 显示地球公转轨道和运动轨迹提示。
- 南北磁极标注。
- 粒子沿磁力线运动。
- 键盘数字 `1`、`2`、`3` 切换磁场模式。

本模块是面向儿童的教学示意，不用于精确物理计算。

## 五、Canvas 场景切换与播放状态兼容

太阳系总览和成员1专题均作为 `CanvasRuntime` 中的互斥主场景运行：

- 太阳系总览的场景 ID 为 `solar-system`。
- 日食/月食和磁场专题的场景 ID 分别为 `eclipse` 和 `magnetic`。
- `SceneManager` 同一时间只更新和绘制一个主场景，场景之间不会争用同一个 Canvas。
- 点击“太阳系总览”按钮可从专题场景返回主界面。
- 点击“重置视角”只重置当前场景的视角、模式和动画进度，不会退出当前专题。
- 再次点击当前专题按钮时保持在当前专题，不执行返回操作。
- 播放、暂停和速度倍率由公共动画控制器统一管理，切换场景时保持此前的播放状态。
- 右侧信息面板会根据当前主场景同步更新。

`solarSystemPreview.ts` 继续提供太阳系绘制和换肤所需的共享数据与绘制工具，
实际主场景切换由 `CanvasRuntime` 和 `SceneManager` 负责。
