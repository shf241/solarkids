# SolarKids 成员1日月食与磁场模块说明

## 一、负责范围

成员1负责：

- 模块2：日食与月食模拟。
- 模块3：太阳磁场与地球磁场演示。

两个模块均使用成员3提供的公共 `CanvasRuntime`，不创建额外的
`requestAnimationFrame` 循环。

## 二、文件结构

```text
src/canvas/scenes/
├── eclipseScene.ts
├── magneticScene.ts
├── registerMember1Scenes.ts
└── sceneVisuals.ts
```

- `eclipseScene.ts`：日食、月食、全景和地球视角。
- `magneticScene.ts`：太阳磁场、地球磁场和磁场对比模式。
- `registerMember1Scenes.ts`：统一注册两个专题场景。
- `sceneVisuals.ts`：专题场景共用的背景、按钮、时间轴和标签绘制工具。

## 三、日食与月食模块

场景 ID 为 `eclipse`，现有“日食/月食”按钮会自动切换到该场景。

功能包括：

- 日食和月食模式切换。
- 全景视角和地球视角切换。
- 太阳、地球、月球关键位置标注。
- 本影方向和遮挡关系演示。
- 时间轴和事件过程提示。
- 播放、暂停和统一时间倍率控制。
- 键盘数字 `1`、`2` 切换日食和月食。
- 键盘 `V` 切换观察视角。

## 四、磁场模块

场景 ID 为 `magnetic`，现有“磁场”按钮会自动切换到该场景。

功能包括：

- 太阳磁场和地球磁场对比。
- 太阳磁场单独观察。
- 地球磁场单独观察。
- 南北磁极标注。
- 粒子沿磁力线运动。
- 太阳风粒子和地球磁场屏障关系演示。
- 键盘数字 `1`、`2`、`3` 切换磁场模式。

本模块是面向儿童的教学示意，不用于精确物理计算。

## 五、静态预览兼容

原有 `solarSystemPreview.ts` 增加了激活状态控制：

- 进入专题场景时暂停旧预览的绘制和指针响应。
- 点击“重置视角”时退出专题场景并恢复太阳系预览。
- 恢复预览时重置缩放、选中地球并更新右侧信息面板。

因此专题场景和旧静态预览不会同时争用同一个 Canvas。
